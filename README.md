Burger Heaven is a full-stack burger ordering website where users can sign up, sign in, and place orders online. It also includes an admin panel to manage orders. The project is built with Node.js, Express, MySQL, and vanilla HTML/CSS/JS, and is fully responsive across devices.

🚀 Features

🔐 User authentication (Sign Up / Sign In with sessions)

🍔 Burger ordering system with modal form

👨‍💼 Admin dashboard for managing orders

📱 Responsive design with mobile-friendly navigation (hamburger menu)

💾 MySQL database for storing users and orders

⚡ Session-based authentication (no localStorage)

🛠 Tech Stack

Frontend:

HTML5, CSS3, JavaScript

Backend:

Node.js, Express.js

Database:

MySQL
